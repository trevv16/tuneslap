# Demo Audio Files

Place your demo audio files in this directory. They will be uploaded to MinIO when the server starts in demo mode.

## Required Files

| Filename | Description | Duration |
|----------|-------------|----------|
| applause.mp3 | Audience applause sound | 3-10 seconds |
| drum-roll.mp3 | Drum roll sound effect | 3-10 seconds |
| laughter.mp3 | Laughter sound effect | 3-10 seconds |
| air-horn.mp3 | Air horn sound effect | 3-10 seconds |
| whoosh.mp3 | Whoosh/swoosh sound effect | 3-10 seconds |
| bell-ding.mp3 | Bell ding/chime sound | 3-10 seconds |
| boing.mp3 | Boing/spring sound effect | 3-10 seconds |
| tada.mp3 | Ta-da/fanfare sound effect | 3-10 seconds |

## Finding Free Sound Effects

- [Freesound.org](https://freesound.org) - Creative Commons licensed sounds
- [Pixabay Sound Effects](https://pixabay.com/sound-effects/) - Free for commercial use
- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sound effects

## File Requirements

- Format: MP3
- Duration: 3-10 seconds
- Quality: 128kbps or higher
- No licensing restrictions for demo use
